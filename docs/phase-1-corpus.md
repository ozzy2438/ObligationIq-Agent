# Phase 1: local regulatory corpus

The owner authorised continuation after Phase 0. This delivery acquires the ten regulatory source families, preserves their provenance, and builds a local searchable corpus. It creates no customer population, obligation approval, compliance decision or cloud workload.

## Reproduce

Use Python 3.12 for the optional corpus dependencies. From the repository checkout:

```sh
python3.12 -m venv .venv
. .venv/bin/activate
python -m pip install -e '.[test,corpus]'
python scripts/acquire_corpus.py --model
LOCAL_EMBEDDING_ENABLED=true python -m src.dataplane.corpus build
LOCAL_EMBEDDING_ENABLED=true python scripts/verify_corpus.py
pytest
python scripts/check_boundaries.py
```

The first acquisition needs internet access for public PDFs, Python packages and approximately 91 MB of model assets. It needs no login, subscription or model API. Every download is SHA-256 checked before becoming usable. Cached acquisitions verify local bytes and make no HTTP requests. A remote change fails; reviewing and updating a source pin is a deliberate version change.

Subsequent builds reuse the persisted corpus when its manifest, model and parser fingerprints agree. A changed source or parser rebuilds the index; unchanged embedding inputs still reuse their disk cache. Interrupted embedding runs retain completed batches. Reproduction from an empty checkout computes local vectors once; no hosted cache or machine-specific binary is published.

```sh
# Deterministic lexical baseline; no local-model opt-in is needed.
python -m src.dataplane.corpus search --regime VIC --as-of 2026-09-12 \
  --query 'minimum assistance payment difficulties'

# Explicit local semantic retrieval; never enables Azure.
LOCAL_EMBEDDING_ENABLED=true python -m src.dataplane.corpus search \
  --method semantic --regime NERL_NERR --as-of 2026-09-12 \
  --query 'registration of life support equipment'
```

`python -m src` remains the original zero-network dry-run smoke path. `LLM_MODE` and `LLM_ALLOW_LIVE` govern Azure text inference. The separate `LOCAL_EMBEDDING_ENABLED` flag authorises only local public-corpus embedding through the same sole model-call module. No source code silently switches an Azure request to a different provider.

## Provenance and boundaries

[SOURCES.md](../data/SOURCES.md) is the readable inventory; [source-manifest.json](../data/source-manifest.json) records exact URLs, checksums, source version, publication/effective information, snapshot date, jurisdictions, terms and extraction ranges. Whole PDFs and full extracted pages stay local. The index selects the two pilot families from the large NERR, NERL and Victorian instruments; unrelated core instrument parts are not indexed. Broader billing, exemption and reporting guidance is context only.

References are resolved in explicit, ordered source ranges, so a table of contents or the same number in a different instrument cannot become the source clause. Missing expected anchors halt the build. Long clauses retain their parent reference across overlapping token windows; no invented subclause numbering is introduced. Unnumbered narrative, forms and reference tables carry `page_context`, not a fabricated clause reference. PDF page numbers are physical, one-based PDF pages, which may differ from printed page labels. Retained footnotes and page furniture can appear in extracted text; tabular reading order still requires source inspection before extracting operational requirements.

The source documents are untrusted evidence. Instructions inside them are not commands to the application. Nothing in this phase executes document text or sends it to a remote model.

Retrieval requires an explicit regime. `NERL_NERR` and `VIC` are never mixed; common AEMO material is visibly tagged `NEM_CONTEXT`. A SA law consolidation is a statutory foundation, not proof of identical state implementation. Local application laws, NSW B2B overlays and definitions in referenced instruments still require verification for each obligation in Phase 2.

This is a **12 September 2026 snapshot**, not a complete legal history. `valid_from` records the start of verified snapshot coverage; it is distinct from an instrument's `effective_from`. Unknown or staged commencement is not invented. Queries outside verified snapshot coverage return no matches. No future or historical legal applicability is implied. Victoria's October 2026 amendments and future AEMO versions are excluded.

## Measured verification and limits

[phase-1-verification.json](phase-1-verification.json) is generated by the offline verification script. It records source/page/clause counts, ten fixed citation-location checks and a replay with network and embedding execution disabled. Unit tests cover anchor failure, cross-page clauses, checksum changes, explicit embedding opt-in, redaction invocation, zero-reservation cache hits and regime/date isolation.

These are engineering checks, not human legal verification. Semantic retrieval quality has not been benchmarked against the lexical baseline. No accuracy or business impact claim is made. Embeddings use the pinned Apache-2.0 MiniLM ONNX model on CPU, with attention-masked mean pooling and L2 normalisation. Local calls are logged as `mode=local`, with zero external AUD charge and no paid reservation. Local electricity, hardware and download costs are unmeasured.

Raw PDFs, extracted text, vectors and model weights are excluded from Git. AEMC and ESC code material has restrictive or unspecified reuse terms; this local research build does not assert an open licence or permission for commercial/public full-text redistribution. The manifest preserves each source's actual terms and required attribution. The source content is not republished in the repository.

Phase 2 must create 25–40 source-linked candidate obligation records and obtain actual human verification before any record is usable by controls. Source acquisition and successful retrieval cannot satisfy that approval gate.
